# Changelog

## 0.10.3 - Public beta

### Added
- Three additional AI services in the AI catalog: Tencent Hunyuan, Baidu Wenxin and Tencent Yuanbao.
- Optional **Open Pointix when Obsidian starts** behavior.
- Optional **Pin Pointix tab** behavior using Obsidian's tab pinning.
- Pointix entry in the new-tab screen and desktop tab bar, both configurable.
- Clearer subcategories for documents, data, code and visual formats.
- Existing-file actions for compatible cards, including vault files and user-selected device files.

### Changed
- Commands use shorter names so Obsidian can display them cleanly under the plugin name.
- Support and donation information is exposed in settings and documentation.
- Release metadata and documentation were refreshed for Community directory and BRAT distribution.

### Notes
- The plugin remains a beta.
- Desktop testing has been performed on Linux and with Obsidian's mobile emulation. Real-device Android/iOS and Windows/macOS coverage should continue during beta testing.
